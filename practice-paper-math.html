Algebra

\(x^2 - y^2 = (x-y)(x+y)\)
\(x^3 \pm y^3 = (x \pm y)(x^2 \mp xy + y^2)\)

Sequences and Series

\(T_n = a + (n-1)d\)
\(S_n = \dfrac{n}{2}[2a + (n-1)d]\)
\(T_n = ar^{n-1}\)
\(S_n = \dfrac{a(r^n - 1)}{r - 1} \quad (r \neq 1)\)
\(S_\infty = \dfrac{a}{1 - r} \quad (-1 < r < 1)\)

Analytical Geometry

\(d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\)
\(M\left(\dfrac{x_1 + x_2}{2} ; \dfrac{y_1 + y_2}{2}\right)\)
\(m = \dfrac{y_2 - y_1}{x_2 - x_1}\)
\(y - y_1 = m(x - x_1)\)
\((x - a)^2 + (y - b)^2 = r^2\)

Calculus

\(f'(x) = \lim_{h \to 0} \dfrac{f(x + h) - f(x)}{h}\)
If \(f(x) = ax^n\), then \(f'(x) = anx^{n-1}\)
\(m_{tangent} = f'(x_1)\)
\(m_{normal} = -\dfrac{1}{m_{tangent}}\)

Trigonometry

\(\sin^2 \theta + \cos^2 \theta = 1\)
\(\tan \theta = \dfrac{\sin \theta}{\cos \theta}\)
\(\sin(\alpha \pm \beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta\)
\(\cos(\alpha \pm \beta) = \cos\alpha\cos\beta \mp \sin\alpha\sin\beta\)
\(\sin 2\alpha = 2\sin\alpha\cos\alpha\)
\(\cos 2\alpha = \cos^2\alpha - \sin^2\alpha\)
\(\cos 2\alpha = 1 - 2\sin^2\alpha\)
\(\cos 2\alpha = 2\cos^2\alpha - 1\)

Sine, Cosine & Area Rules

\(\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C}\)
\(a^2 = b^2 + c^2 - 2bc\cos A\)
Area \(\Delta ABC = \dfrac{1}{2}ab\sin C\)

Statistics

\(\bar{x} = \dfrac{\sum x_i}{n}\)
\(\sigma^2 = \dfrac{\sum (x_i - \bar{x})^2}{n}\)
\(P(A) = \dfrac{n(A)}{n(S)}\)
\(P(A \text{ or } B) = P(A) + P(B) - P(A \text{ and } B)\)

Financial Mathematics
