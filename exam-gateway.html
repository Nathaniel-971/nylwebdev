Examination Gateway

Enter your credentials to access the live exam session.

This is the AE entry point. You must be a registered applicant with a Student ID and Security Code. These were generated when you applied.

What you need

  • 13-digit Student ID (from admission.html)
  • 6-digit Security Code (from admission.html)
  • Printed Answer Book template (from resources.html)
  • A working camera + stable internet

What you don't need

  • A separate login password (the code is your key)
  • A downloadable question paper (it appears on screen)
  • To be enrolled yet (applicants can enter)
