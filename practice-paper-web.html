CASE STUDY: THE IFB STUDENT PORTAL PROJECT

The Project: A web development team is building the new IFB Student Portal. The main project folder is named IFB_Portal. Inside this folder, there is a main file named index.html. There is also a folder named css containing a file named style.css, and a folder named images containing a file named logo.png.

Performance Data: The team tests the index.html page. It currently takes exactly 8 seconds to fully load. The lead developer breaks down the load time:

  • Images: 4 seconds
  • CSS: 1 second
  • JavaScript: 3 seconds

User Survey: The team surveys 1,000 students to find out what device they use to access the portal:

  • Mobile Phones: 60%
  • Laptops: 25%
  • Tablets: 10%
  • Desktop PCs: 5%

Screen Resolutions: The most common screen sizes are 1080 x 1920 (Mobile) and 1920 x 1080 (Laptop). The team uses a standard high-definition image with an aspect ratio of 16 : 9 on the main page.
