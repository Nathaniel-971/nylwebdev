INFORMATION SHEET
Tree Traversal Logic

Depth-First Search (DFS): Explore as far as possible along each branch before backtracking.

Breadth-First Search (BFS): Explore all nodes at the present depth prior to moving on to nodes at the next depth level.

Asynchronous Execution

Blocking: Code execution halts until a task is complete.

Non-blocking: Code continues executing while a task (like a network request) happens in the background.

State Management Principles

Single Source of Truth: The state of the entire application is stored in one central object tree.

Immutability: State is never modified directly; instead, a new state object is created.

Rendering Performance

Layout/Reflow: Calculating the geometry and position of elements.

Paint: Filling in the pixels for the visual representation of elements.
