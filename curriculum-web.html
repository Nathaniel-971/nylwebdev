IFB AQ-B Curriculum

Front-End Web Development

12-Month Intensive Track

Curriculum Philosophy

The IFB AQ-B track is designed to produce elite Front-End Engineers, not just "website builders." We do not rely on drag-and-drop site builders. Every student must write raw code, understand browser rendering, and master the modern JavaScript ecosystem.

The curriculum is heavily project-based. You are assessed entirely on what you can build, optimize, and deploy to a live server.

The Core Stack

01

Semantic HTML5 & Document Structure

  • Accessibility (ARIA roles, screen readers)
  • SEO best practices and meta tags
  • Forms, client-side validation, and file uploads
02

Advanced CSS3 & Responsive Design

  • Flexbox and CSS Grid architecture
  • Media queries and mobile-first design
  • CSS Variables, transitions, and keyframe animations
  • Preprocessors (SASS/SCSS)
03

JavaScript & DOM Manipulation

  • ES6+ syntax (Arrow functions, destructuring, spread/rest)
  • The Document Object Model (DOM) and Event Listeners
  • Asynchronous JavaScript (Promises, async/await, Fetch API)
  • Error handling and debugging in Chrome DevTools
04

Modern Frameworks & State Management

  • Introduction to React.js
  • Components, Props, and State
  • React Hooks (useState, useEffect, useContext)
  • Client-side Routing (React Router)
05

Git, GitHub & Deployment

  • Version control fundamentals (commit, push, pull, branch)
  • Resolving merge conflicts
  • Deploying live static sites via Vercel and Netlify
  • Setting up custom domains
06

API Integration & Security

  • Consuming REST APIs (JSON)
  • Handling authentication (JWT tokens)
  • Preventing Cross-Site Scripting (XSS) and sanitizing inputs
