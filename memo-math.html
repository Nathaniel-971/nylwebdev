MARKING GUIDELINES

1. Tick Marks (✓): The symbol ✓ indicates exactly where a single mark is awarded for a specific step.

2. Alternative Methods (OR): Where an alternative method is mathematically valid, it is marked with OR. Accept any correct alternative unless explicitly stated otherwise.

3. Consistent Accuracy (C.A.): If a student makes an error in an earlier step (e.g., finding the wrong derivative) but uses that incorrect value correctly in subsequent steps, they are awarded C.A. marks.

How C.A. works in this memo:
If the correct answer is 10, but the student gets 8. In the next step, they multiply by 2. (8 x 2 = 16).
✓ C.A. Accepted: They get the mark for the multiplication step.
✗ C.A. Not Accepted: They do NOT get the final accuracy mark (because 16 is not 20).

4. Penalties:

  • Penalise ONLY ONCE for a wrong unit or rounding error in a multi-step question.
  • Do not penalise for missing units unless the question specifically asks for them.
  • If a student writes an incorrect final answer but doesn't cross out the correct working, mark the correct working.

5. Mathematical Notation: Accept $\frac{1}{2}$ or 0.5. Accept \(\pm\) where appropriate. If a student provides two answers where only one is correct without indicating choice, award the mark but penalise in the final answer if applicable.

QUESTION 1 (Algebra) [30 Marks]
1.1 (2 marks)
✓ \(x^2 - 5x + 6 = 0\)
✓ \((x-2)(x-3) = 0\) [Factorisation]
✓ \(x = 2\) or \(x = 3\) [Values]
1.2 (3 marks)
✓ \(2^{2x+1} - 5 \cdot 2^x + 2 = 0\)
✓ \(2(2^x)^2 - 5(2^x) + 2 = 0\) [Standard form]
Let \(k = 2^x\): \(2k^2 - 5k + 2 = 0\)
✓ \((2k - 1)(k - 2) = 0\) [Factorising]
\(k = \frac{1}{2}\) or \(k = 2\)
✓ \(2^x = 2^{-1} \implies x = -1\) [Correct exponent]
✓ \(2^x = 2^1 \implies x = 1\)
C.A. Applies: If factorisation is wrong but values substituted correctly into \(2^x\), award C.A. marks.
1.3 (4 marks)
✓ \(\sqrt{2x+5} - x = 1\)
✓ \(\sqrt{2x+5} = x+1\) [Isolating root]
✓ \(2x+5 = x^2 + 2x + 1\) [Squaring both sides]
✓ \(x^2 - 4 = 0 \implies (x-2)(x+2) = 0\)
\(x = 2\) or \(x = -2\)
✓ Check \(x=2\): \(\sqrt{9} - 2 = 1\) (Valid). Check \(x=-2\): \(\sqrt{1} - (-2) = 3 \neq 1\) (Invalid).
✓ Final Answer: \(x = 2\)
Not Accepted: Giving \(x = -2\) as a solution without checking. (1 mark lost).

QUESTION 6 (Optimization) [14 Marks]
6.1 (7 marks)
✓ Let width = \(x\), length = \(2x\), height = \(h\).
✓ Surface Area \(= 2x^2 + 2(2xh) + 2(xh) = 108\)
✓ \(6xh = 108 - 2x^2 \implies h = \frac{108 - 2x^2}{6x}\)
✓ Volume \(V = l \cdot w \cdot h = (2x)(x)\left(\frac{108 - 2x^2}{6x}\right)\)
✓ \(V = 36x - \frac{2}{3}x^3\)
✓ \(\frac{dV}{dx} = 36 - 2x^2 = 0 \implies 2x^2 = 36 \implies x^2 = 18 \implies x = 3\sqrt{2}\)
✓ Check nature: \(\frac{d^2V}{dx^2} = -4x < 0\) for \(x>0 \implies\) Maximum.
✓ Dimensions: Width = \(3\sqrt{2}\) cm, Length = \(6\sqrt{2}\) cm, Height = \(2\sqrt{2}\) cm.
6.2 (3 marks)
✓ Let width = \(x\). The two widths use \(2x\) fencing.
✓ Length uses \(100 - 2x\) fencing.
✓ Area \(A = x(100 - 2x) = 100x - 2x^2\).
6.3 (4 marks)
✓ Maximize \(A\): \(\frac{dA}{dx} = 100 - 4x = 0\)
✓ \(4x = 100 \implies x = 25\)
✓ Width = 25 m. Length = \(100 - 2(25) = 50\) m.
✓ Maximum Area = \(25 \times 50 = 1250 \text{ m}^2\)
