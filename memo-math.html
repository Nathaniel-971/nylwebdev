MARKING GUIDELINES

1. Tick Marks (✓): The symbol ✓ indicates exactly where a mark is awarded for a specific step.

2. Alternative Methods (OR): Where an alternative method is mathematically valid, it is marked with OR. Accept any correct alternative unless explicitly stated otherwise.

3. Consistent Accuracy (C.A.): If a student makes an error in an early step but uses that incorrect value correctly in subsequent steps, they are awarded C.A. marks.

How C.A. is Applied:
If the correct answer is 10, but the student gets 8. In the next step, they multiply by 2. (8 x 2 = 16).
Award: The mark for the multiplication step (because they correctly multiplied their wrong value).
Do NOT Award: The final accuracy mark (because 16 is not the correct final answer of 20).

4. When NOT to Award Marks:

  • Answers Only: If a student writes only the final answer without showing the required calculation steps, award 0 marks (unless specifically asked for an answer only).
  • Missing Units: If units are omitted, penalise only once in the final step.
  • Wrong Formula: If the initial formula or derivative is completely wrong, do not award C.A. marks for subsequent correct algebra on that wrong formula.
  • Extraneous Roots: In equations with square roots or logs, if a student does not reject invalid roots, deduct 1 mark.

QUESTION 6 (Optimization) [14 Marks]
6.1 (7 marks)
✓ Let width = \(x\), length = \(2x\), height = \(h\).
✓ Surface Area \(= 2x^2 + 2(2xh) + 2(xh) = 108\)
✓ \(6xh = 108 - 2x^2 \implies h = \frac{108 - 2x^2}{6x}\)
✓ Volume \(V = l \cdot w \cdot h = (2x)(x)\left(\frac{108 - 2x^2}{6x}\right)\)
✓ \(V = 36x - \frac{2}{3}x^3\)
✓ \(\frac{dV}{dx} = 36 - 2x^2 = 0 \implies 2x^2 = 36 \implies x^2 = 18 \implies x = 3\sqrt{2}\)
✓ Check nature: \(\frac{d^2V}{dx^2} = -4x < 0\) for \(x>0 \implies\) Maximum.
✓ Dimensions: Width = \(3\sqrt{2}\) cm, Length = \(6\sqrt{2}\) cm, Height = \(2\sqrt{2}\) cm.
6.2 (3 marks)
✓ Let width = \(x\). The two widths use \(2x\) fencing.
✓ Length uses \(100 - 2x\) fencing.
✓ Area \(A = x(100 - 2x) = 100x - 2x^2\).
6.3 (4 marks)
✓ Maximize \(A\): \(\frac{dA}{dx} = 100 - 4x = 0\)
✓ \(4x = 100 \implies x = 25\)
✓ Width = 25 m. Length = \(100 - 2(25) = 50\) m.
✓ Maximum Area = \(25 \times 50 = 1250 \text{ m}^2\)
